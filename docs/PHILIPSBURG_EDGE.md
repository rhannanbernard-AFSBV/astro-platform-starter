# Philipsburg edge — what makes this build local

Differentiators aimed at **Front Street / cruise-port** service, not generic Toast clones.

| Edge | What guests/staff get |
|------|------------------------|
| **USD + XCG everywhere** | Dual prices on guest menu, checkout, tips, and pay-at-counter copy |
| **Table-deep-link QR** | `/order?table=12` + printable `/order/qr?table=12` tents |
| **Cruise-friendly welcome** | Philipsburg / SXM banner + estimated kitchen wait |
| **Tip intent on guest order** | Optional tip presets land on the POS check before payment |
| **Yard brand** | Jamaican categories (Jerk · Seafood · Ital · Patties) + Front Street address |
| **Floor + bar unity** | Guest tickets fire both stations; shift day-part already splits revenue |

## URLs
